## 🔍 2. How Ingredient Detection Works
The system uses a "Hybrid Detection" strategy to ensure accuracy even with complex photos.

### **Phase A: YOLOv8-World (Real-time Detection)**
- **What it is**: A state-of-the-art object detection model that can find specific objects in milliseconds.
- **The "World" Advantage**: Unlike standard YOLO models, the "World" version can be told what to look for at runtime. We've programmed it with `GROUNDING_CLASSES` like "whole chicken", "rosemary", and "red onion".
- **Optimization**: We enhance the image contrast and sharpness before detection to help the model "see" better.

### **Phase B: Vision-Language Model (VLM) Fallback**
- **What it is**: If YOLO fails to find anything, or if "Maximum Accuracy Mode" is enabled, the system calls **LM Studio** using a Vision model (e.g., `moondream`).
- **The Logic**: It sends the actual image pixels to the LLM and asks: *"Identify the edible food ingredients in this image."* This is slower but much more intelligent than YOLO.

## 🍳 3. Recipe Generation (The Culinary Brain)
Once ingredients are detected (e.g., `["Chicken", "Tomato", "Onion"]`), the list is sent to **LM Studio** with a specialized prompt.

- **Model used**: Usually a text-heavy model like `Llama 3`.
- **The Prompting Strategy**: We use "Structured Prompting" to force the AI to return exactly 3 recipes in a specific markdown format:
    - **Time & Heat**: Practical cooking metrics.
    - **Pantry Items**: The AI assumes you have basics like oil, salt, and water.
    - **Instructions**: Step-by-step logic.
    - **Chef's Secret**: Expert tips for that specific dish.
